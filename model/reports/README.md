# Versioned reports

[Selected-week 30/30 MW tariff evidence](selected_weeks_30mw/README.md) is the current
research snapshot: all controls, both hourly strengths, the lossless sensitivity,
figures, exact configurations/specifications and provenance.

Keep snapshots compact and immutable. Full networks, raw downloads, prepared annual
series and exploratory runs belong in the Git-ignored data/results directories.
Create a new snapshot when assumptions or findings change; do not quietly replace
published tables with a later experiment. The source package and full local run
index remain in [model/README.md](../README.md) and [results/README.md](../results/README.md).
